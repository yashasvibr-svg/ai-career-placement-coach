# Capstone Reflection

## Project Overview

This project is an AI Career Coach designed to help college students understand their placement readiness and receive personalized career preparation guidance.

The application allows a student to enter an assessment score and readiness level. The system sends this information to an AI career coaching service and generates practical preparation guidance.

## What I Built

I built a Next.js application with:

- Placement readiness assessment
- Career guidance interface
- AI-powered career coaching
- Server-side API route
- Anthropic AI SDK integration
- Input validation
- Error handling
- Automated tests
- Responsive user interface
- Accessibility and SEO improvements

## AI-Assisted Development

I used AI assistance during development to help with:

- Project planning
- Generating and improving React/Next.js components
- Creating API routes
- Integrating the AI service
- Debugging errors
- Writing automated tests
- Improving UI and accessibility
- Reviewing implementation decisions

I did not rely on AI output without verification. I tested the application locally and checked that the important features worked correctly.

## Testing

The project includes automated tests for the assessment and career coach functionality.

The final test run completed successfully:

- Test files passed: 2
- Tests passed: 8
- Tests failed: 0

I also manually tested the application through the browser.

## Challenges

One of the main challenges was configuring the AI service because it requires an API key. I learned how environment variables can be used to keep API credentials outside the application source code.

Another challenge was debugging the API integration and making sure invalid requests were handled correctly.

## What I Learned

Through this project I learned:

1. How Next.js API routes work.
2. How frontend and backend code communicate through HTTP requests.
3. How to integrate an AI API into a web application.
4. How to use environment variables for configuration.
5. How to write and run automated tests.
6. How to debug errors using the browser and terminal.
7. How AI-assisted development can speed up development while still requiring human verification.
8. How performance, accessibility, best practices, and SEO can be evaluated using Lighthouse.

## AI Workflow

My development process was:

1. Understand the feature requirements.
2. Ask AI for an implementation approach.
3. Implement the suggested solution.
4. Run the application locally.
5. Test the feature manually.
6. Run automated tests.
7. Fix errors found during testing.
8. Review the final implementation.
9. Commit the working changes to Git.

## Final Reflection

This project helped me understand how a modern AI-powered web application is structured from frontend to backend.

The most important lesson was that AI can assist with coding and problem solving, but the developer still needs to understand the code, test the implementation, identify problems, and make the final decisions.

I now have a better understanding of building, testing, debugging, and deploying an AI-enabled web application.
